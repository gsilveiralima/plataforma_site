# Portfólio técnico

Site estático pessoal para apresentar projetos de desenvolvimento de software, automação, inteligência artificial aplicada e cibersegurança.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Executar localmente

```bash
python -m http.server 8000
```

Depois abra `http://localhost:8000`.

## Diretriz de conteúdo

O portfólio deve apresentar somente competências, projetos e resultados que possam ser sustentados por código, documentação ou evidências verificáveis.

Projetos institucionais devem ser descritos sem dados pessoais, credenciais, material reservado ou procedimentos internos.
